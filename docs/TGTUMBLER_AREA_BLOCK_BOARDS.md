Master最新指定：L1エリアブロックは地域説明付きで、既存個別エリアへのInlineKeyboardを横3列基本に配置する。本番配備・投稿は一括で後日。

根拠：Notion 地域ボードD01–D20（D04/05/10/11）、エリアBBS 3階層ナビ採用仕様§3、GitHub GateApp-Bot Current #7。

## 採用構成
1. L0 全国エリアボード：13ブロックへの本文テキストリンク。
2. L1 ブロック：名称→対象エリアの区別と選び方→移動先の青い「📝 投稿メニュー」からBot DMで投稿する手順→3列エリアボタン→検索／フィルター→共通雑談／総合案内へ戻る。
3. L2 個別エリア：既存の投稿メニューと親ボードへ戻る入口。

## 記録と実装
- Sourceの topicBoardContent.ts に13地域の説明案と固定L2投稿手順を収録。東京の池袋・新宿・渋谷・品川・都心・区東部・都下、関西の大阪キタ／ミナミは個別の区分として説明する。
- 正確な地理的境界はNotion旧決定でも未確定。一般地理知識で市区町村・駅の所属を創作しない。既存正式説明に基づいて承認した地域詳細を既存 topic_board_posts.approved_scope_text に登録するまで publish は AREA_BLOCK_SCOPE_NOT_APPROVED で拒否。
- menuPanelRenderer.ts の renderAreaBlockBoard は子エリアを3列、検索/フィルター、共通雑談/総合案内へ戻るを下部に保持する。ブロック自身に投稿作成ボタンは追加しない。
- topicBoardHandlers.ts は全リンク・詳細説明が揃ってから既存Bot投稿を編集/投稿する。本番公開フラグは既定OFF。
