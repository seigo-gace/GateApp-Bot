## A. 3グループ共通ルール

### 1. 投稿先

投稿はTopicの用途に合わせて行ってください。投稿・募集は案内されたメニューから作成します。

### 2. スポイラー

すべての画像・動画には投稿者自身でスポイラー（ネタバレ）を設定してください。 画像・動画の無断転載、権利侵害は禁止です。

### 3. URL・外部誘導

マルウェア、フィッシング、スパム防止のため、 URLの直接投稿は禁止します。必要なリンクは指定の「🔗ボタン作成」を使います。この機能も、不正誘導や無許可宣伝に利用できません。

### 4. 他人のコンテンツ

他人のプロフィール、画像、動画、会話を本人の承諾なしに保存・転送・転載・外部公開してはいけません。

### 5. 対人行為とBot

誹謗中傷、脅迫、しつこい連絡、強要を禁止します。無許可の外部Bot招待、審査・制限の回避、なりすまし、username等の参加条件違反も禁止します。

### 6. Botによる管理

Botが規約・規則・ルール違反をモニタリングし、投稿削除、警告、Mute、BAN等を行います。対象情報と保存目的は③Privacy Policyに定めます。

### 7. 通常違反（累積5段階）

| 違反回数 | 措置 |
| --- | --- |
| 1回目 | 違反投稿の削除と警告 |
| 2回目 | 1時間Mute |
| 3回目 | 12時間Mute |
| 4回目 | 24時間Mute |
| 5回目 | BAN（再参加禁止） |

Mute中は投稿・発言を制限し、閲覧は可能です。違反回数は累積管理とし、現時点で自動リセット期限は定めません。段階的措置中も該当する違反投稿は削除対象です。
